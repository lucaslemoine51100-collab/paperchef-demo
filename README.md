# PaperChef — démonstration pour GitHub Pages

Cette copie permet de choisir Cuisinier, Magasinier ou Diététique sans mot de passe. Les essais restent dans le navigateur de chaque visiteur. Aucune connexion à la vraie base PaperChef.

## Mettre en ligne
1. Décompressez PaperChef-GitHub-Pages.zip.
2. Sur GitHub, créez un dépôt public (par exemple paperchef-demo).
3. Dans le dépôt : Add file → Upload files. Importez tout le contenu du dossier décompressé, y compris pdf-runtime. index.html doit être à la racine du dépôt. Validez avec Commit changes.
4. Le fichier .nojekyll doit également être présent. S’il est masqué et n’a pas été importé, utilisez Add file → Create new file, nommez-le .nojekyll et enregistrez-le (il peut être vide).
5. Ouvrez Settings → Pages. Sous Source, choisissez Deploy from a branch, puis main et /(root). Cliquez Save.
6. Attendez le déploiement. GitHub affiche le lien du site dans Settings → Pages.

Le nom du dépôt est libre. Cette version fonctionne dans un sous-dossier de GitHub Pages, à la racine ou avec un domaine personnalisé. Le téléchargement initial du moteur et du catalogue peut prendre quelques instants.

Importez les fichiers décompressés, pas seulement le ZIP : GitHub Pages doit trouver index.html.
